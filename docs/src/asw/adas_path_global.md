# adas_path_global.rs — 전역 경로 계획 플레이스홀더

- 경로: `src/asw/adas_path_global.rs`
- 계층: ASW / ADAS Path Planning

## 목적
향후 전역 경로 생성 알고리즘(예: 전체 맵 기반 궤적 계산)을 추가하기 위해 예약된 파일입니다. 현재는 문서화 및 모듈 레이아웃 유지 용도로 빈 스켈레톤만 제공합니다.

## 활용 노트
- 러스트 모듈 트리를 미리 확보해 두었기 때문에, 추후 전역 경로 로직을 구현할 때 이 위치에 러너블/서비스를 배치하면 됩니다.
- 실제 구현이 추가되기 전까지는 컴파일 타깃에 직접적인 영향을 주지 않습니다.
